# Base Mainnet Readiness Checklist

Before using a real wallet or deploying a real contract:

- [ ] Verify the network and chain ID
- [ ] Verify contract addresses
- [ ] Review contract source code
- [ ] Test on a testnet first
- [ ] Never expose private keys
- [ ] Never commit `.env` files
- [ ] Review transaction recipient
- [ ] Review transaction value
- [ ] Review gas settings
- [ ] Confirm the transaction before signing
- [ ] Keep backups of important configuration
- [ ] Monitor deployed contracts
