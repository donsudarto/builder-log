# Base Mainnet Block Inspector

Read-only tool untuk memeriksa block terbaru Base Mainnet.

Data yang diperiksa:

- block number
- block hash
- parent hash
- timestamp
- jumlah transaksi
- umur block

Tujuan utamanya adalah memahami state blockchain yang sedang diamati
dan mendeteksi data RPC yang tidak masuk akal.

Tidak ada private key dan tidak ada transaksi yang dikirim.
