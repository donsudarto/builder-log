# Base Mainnet Event Log Inspector

Blockchain transaction tidak hanya memiliki status sukses atau gagal.

Smart contract juga menghasilkan event logs.

Inspector ini membaca:

- contract address
- jumlah logs
- topics
- event data

Contoh event yang umum:

- Transfer
- Approval
- Deposit
- Withdrawal
- Swap

Tool ini hanya membaca data blockchain.
Tidak membutuhkan private key dan tidak mengirim transaksi.
