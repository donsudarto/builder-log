# Base Mainnet Toolkit

Open-source learning toolkit for Ethereum and Base.

## Scope

This repository focuses on safe blockchain development:

- Base network concepts
- RPC utilities
- Address validation
- Transaction inspection
- ABI concepts
- Smart-contract development
- Testing
- Security
- Mainnet-readiness documentation

The toolkit does not automatically send funds or execute mainnet transactions.
